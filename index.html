Android APK 打包與背景常駐方案指南

因瀏覽器休眠機制，若要達到「螢幕熄滅仍 24 小時偵測」，建議以下兩種 APK 打包方式

1 方式一：利用 Bubblewrap / PWABuilder 一鍵轉成 APK

將本 HTML 網頁部署至 免費託管服務 (如 Vercel, GitHub Pages, Netlify)，接著使用 PWABuilder.com 輸入網址即可直接輸出 .apk 檔安裝到手機。

2 方式二：原生 Android Kotlin 背景服務專案 (推薦最佳穩定度)

若要在手機熄滅螢幕時依然精準偵測 2 小時動態，建議使用 Android Studio 建立 Foreground Service 專案。為您提供核心 Kotlin 程式碼範本：

// SafetyMonitorService.kt - 背景偵測服務
class SafetyMonitorService : Service(), SensorEventListener {
    private lateinit var sensorManager: SensorManager
    private var lastMovementTime = System.currentTimeMillis()
    private val TWO_HOURS_MS = 2 * 60 * 60 * 1000L

    override fun onCreate() {
        super.onCreate()
        sensorManager = getSystemService(SENSOR_SERVICE) as SensorManager
        val accel = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)
        sensorManager.registerListener(this, accel, SensorManager.SENSOR_DELAY_NORMAL)
        startForeground(1, createNotification())
        startCheckTimer()
    }

    override fun onSensorChanged(event: SensorEvent) {
        val x = event.values[0]
        val y = event.values[1]
        val z = event.values[2]
        val delta = Math.sqrt((x*x + y*y + z*z).toDouble()) - SensorManager.GRAVITY_EARTH
        if (Math.abs(delta) > 2.0) {
            lastMovementTime = System.currentTimeMillis() // 刷新最後移動時間
        }
    }

    private fun startCheckTimer() {
        val handler = Handler(Looper.getMainLooper())
        handler.postDelayed(object : Runnable {
            override fun run() {
                if (System.currentTimeMillis() - lastMovementTime >= TWO_HOURS_MS) {
                    sendLinePushNotification("🚨 安全警告：手機已 2 小時無位移！")
                }
                handler.postDelayed(this, 60000) // 每分鐘檢查一次
            }
        }, 60000)
    }

    override fun onAccuracyChanged(s: Sensor?, a: Int) {}
    override fun onBind(i: Intent?) = null
}

3 Google Apps Script (GAS) 免託管發送 LINE Webhook 伺服器代碼

因為瀏覽器端打 LINE API 常會遇到 CORS 跨網域限制，您可以直接複製下方 GAS 腳本，佈署為 Web App 作為代理中繼站：

// Code.gs - Google Apps Script LINE Push Webhook
function doPost(e) {
  var CHANNEL_ACCESS_TOKEN = "您的_CHANNEL_ACCESS_TOKEN";
  var data = JSON.parse(e.postData.contents);
  
  var url = "https://api.line.me/v2/bot/message/push";
  var payload = {
    "to": data.userId,
    "messages": [{ "type": "text", "text": data.message }]
  };
  
  var options = {
    "method": "post",
    "headers": {
      "Content-Type": "application/json",
      "Authorization": "Bearer " + CHANNEL_ACCESS_TOKEN
    },
    "payload": JSON.stringify(payload)
  };
  
  UrlFetchApp.fetch(url, options);
  return ContentService.createTextOutput(JSON.stringify({status: "success"}));
}
